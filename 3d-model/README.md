# Игрушечный лифт: шахта 80×80 мм (PETG, Bambu A1)

Каждая секция — это этаж: дверь без створок, маленькая площадка перед дверью, панель вызова
(отверстия под кнопку и светодиод) и крупные ромбовидные окна. Печатаете одну и ту же секцию
сколько нужно раз и вставляете друг в друга. Шаг этажа 100 мм.

PETG, сопло 0,4, слой 0,2, 3 периметра, заполнение 15–20 % (противовес 100 %).
Потолок кабины — мост ~38 мм: если провиснет, поддержки только под ним.

## Сборка
1. Дно → секции (сколько этажей) → потолок. Стыки посадочные, зазор 0,2 мм.
2. Направляющие продолжаются сами: у секции они выступают языком вверх, торцы срезаны под 45°.
3. Кабина едет на рёбрах боковых стенок, противовес — на Т-рельсах задней стенки.
4. Пол кабины встаёт вровень с порогом двери, когда низ кабины на 22,4 мм выше низа секции (на 1-м этаже — на упорах дна).
5. Канат (≈1 мм): кабина (узел внутри у потолка) → потолок → шкив → потолок → противовес (канат сквозь верхнюю перемычку, узел в пазу над грузом).

Параметры: params.py. Пересборка: `python3 build.py 3` (число этажей), проверка: `python3 check.py 3`.
