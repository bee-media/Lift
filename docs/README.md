# Учебный лифт на ESP32-S3

Что лежит в папке:

| Путь | Что это |
|---|---|
| `firmware/lift/` | прошивка для Arduino IDE (открывайте `lift.ino`) |
| `web/src/` | исходники веб-панели (HTML, CSS, JS) и симулятор лифта |
| `web/dist/index.html` | собранная панель, её можно открыть двойным щелчком: запустится симулятор |
| `tools/build.js` | сборка панели и файла `firmware/lift/webpage.h` |
| `tools/make-schematic.js` | создаёт печатную схему `docs/schematic.html` |
| `tests/` | тесты диспетчера (запуск: `node --test tests/dispatcher.test.js`) |
| `docs/schematic.pdf` | печатная схема и порядок сборки: 6 листов A4 |
| `docs/wiring.md` | что купить, схемы, шлейфы, порядок проверки |
| `docs/shopping-list.md` | список покупок |
| `docs/superpowers/specs/` | дизайн-документ |

## 1. Сначала посмотрите без железа

Откройте `web/dist/index.html` в браузере. Появится панель с симулятором лифта: можно нажимать этажи, менять настройки, смотреть, как работают «попутные».

## 2. Прошивка

Веб-страница **уже вшита в прошивку** (файл `firmware/lift/webpage.h`). Чтобы обновить и прошивку, и страницу, достаточно нажать «Загрузить» в Arduino IDE. Node.js нужен только если вы сами меняете файлы в `web/src`: тогда сначала `node tools/build.js`.

1. Arduino IDE 2.x. В «Менеджере плат» поставьте **esp32 by Espressif версии 3.x** (проверено на 3.3.8).
2. В «Менеджере библиотек» поставьте **Adafruit NeoPixel** (1.12.4 или новее, проверено на 1.15.5). Других библиотек не нужно.
3. Настройки платы, на которых всё проверено: **ESP32S3 Dev Module**, Flash Mode «QIO 80MHz», Flash Size «4MB», Partition Scheme «Default 4MB with spiffs», PSRAM «Disabled», USB CDC On Boot «Disabled», Upload Speed 921600.
4. Откройте `firmware/lift/lift.ino`, подключите плату, «Загрузить».

Ваши сохранённые настройки (домашний Wi-Fi, пароль точки LIFT-Setup, этажи, скорости) при обновлении прошивки **не стираются**. Исключение: если в IDE включена опция «Erase All Flash Before Sketch Upload», тогда стирается всё.

## 3. Первый запуск и сеть

1. Лифт поднимает собственную сеть **LIFT-Setup**. Сначала она открытая. Подключитесь к ней с телефона, откройте `http://192.168.4.1`.
2. **Сразу задайте пароль точки:** «Настройки» → «Сеть» → «Пароль точки LIFT-Setup» (8–63 символа) → «Сохранить пароль». Телефон отключится, подключитесь заново с новым паролем. Пароль хранится отдельно и не стирается кнопкой «Вернуть заводские настройки». Если забудете: прошейте плату с опцией «Erase All Flash Before Sketch Upload».
3. **Домашний Wi-Fi:** там же ниже введите название сети и пароль, нажмите «Сохранить и подключить». Через несколько секунд в блоке «Сеть» появится адрес вида `http://192.168.1.57`. Сеть LIFT-Setup при этом остаётся как запасной вход.
4. Адрес `http://lift.local` на телефонах Android часто не открывается, пользуйтесь IP-адресом из панели.
5. Последующие прошивки можно заливать по воздуху: «Сервис» → «Обновление прошивки» (файл .bin из «Скетч → Экспорт скомпилированного бинарного файла»).

## 4. Калибровка

1. «Калибровка» → «Найти 1-й этаж». Кабина спустится вниз и остановится на упорах.
2. «Калибровать»: лифт сам поднимется на самый верх, запомнит, где стоит каждый датчик, и вернётся вниз.
3. Подберите скорости на странице «Настройки». Если кабина дёргается: уменьшите «Разгон», проверьте регулятор скорости (P, I) в блоке «Железо».

### Если лифт пишет ошибку при запуске

| Сообщение | Что делать |
|---|---|
| Нет расширителей MCP23017 | проверьте провода SDA/SCL, питание 3V3 и адреса модулей (0x20 и 0x22 нужны всегда, 0x21 и 0x23 только для 17+ этажей). Потом «Попробовать снова» |
| Едет не туда | в «Настройки» → «Железо» отметьте «Развернуть мотор» и/или «Развернуть энкодер» |
| Кабина не едет, возможно застряла | проверьте энкодер: без него регулятор не видит движения (или включите режим без энкодера) |
| Не нашёл первый этаж / Не вижу датчик на N этаже | проверьте магнит, датчик и провод этого этажа |

## 4а. Мотор без энкодера (временно)

Пока энкодер не подключён:
1. «Настройки» → «Железо» → снимите галку **«Энкодер подключён»**. Лифт заново найдёт первый этаж. На вкладке «Играть» появится плашка «Режим без энкодера».
2. Положение считается по времени работы мотора, останавливается кабина по **датчикам Холла** (они и MCP23017 нужны). Пока датчик целевого этажа не сработает, лифт ползёт на малой скорости.
3. Запустите «Калибровать» (нужно минимум 3 этажа): лифт измерит скорость по времени между датчиками и подберёт «Мощность на 1 мм/с». Стартовое значение 0,45.
4. Точность ниже, чем с энкодером. Если лифт часто пишет «Не вижу датчик на N этаже», запустите калибровку ещё раз.
5. Когда придёт мотор с энкодером: подключите его, поставьте галку обратно и снова нажмите «Калибровать».

## 5. Что дети увидят и смогут делать

* Нажимать кнопки этажей на лифте и на экране (держать 5 секунд, чтобы назначить «дом» лифта).
* Видеть на экране очередь вызовов, датчики Холла, скорость и счётчик мотора.
* Сравнивать три правила работы: «Попутный вниз», «По очереди», «Попутный в обе стороны».
* Включить «Лифт сам вызывает себя», замедленный показ, «сломать датчик» и смотреть, что лифт сообщает.

## 6. Что проверено и что нет

Проверено на вашей плате: прошивка собирается, загружается, поднимает сеть LIFT-Setup, панель открывается с телефона, подключение к домашнему Wi-Fi, пароль точки доступа. Диспетчер и панель проверены автотестами (14 тестов) и в браузере.

Не проверено на настоящем лифте (нужны детали): работа с датчиками Холла, расширителями, мотором, светодиодами и кнопками; подбор регулятора скорости и зоны датчика; режим без энкодера. При первом запуске сообщения лифта в «Сервис» → «Журнал» подскажут, что не так.

Датчик через окно (расстояние ~12 мм): проверьте на одной секции с реальным магнитом до покупки всех датчиков.
